# CryptoYar
مدیریت فعالیت و درآمد سایت‌های کسب درآمد با ثبت دستی زمان و درآمد.

## v0.1
- داشبورد هدف روزانه
- فهرست سایت‌ها
- WebView داخلی
- زمان‌سنج دستی
- محاسبه درآمد بر دقیقه
- آدرس عمومی BTC و USDT
- ساخت خودکار APK با GitHub Actions

هیچ کلیک خودکار، ربات، بازدید جعلی یا دور زدن قوانین سایت‌ها در برنامه وجود ندارد.
